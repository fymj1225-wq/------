# レストア原価管理

車両レストアの原価表を、車両ごとに管理するためのアプリです。
いただいた「車両管理表.xlsx」の構成をベースにしています。

## 使い方

`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。
インストールもインターネット接続も不要です。

- そのまま開く … `index.html` をダブルクリック
- 社内で共有したい場合 … このフォルダごと共有フォルダや社内サーバーに置く

初回起動時は、見本として「ユーノス（管理番号 218287）」のデータが1件入っています。
不要になったら「車両を削除」で消してください。

## 画面の構成

### トップ：車両アカウント一覧
起動するとまずこの画面です。1台＝1アカウントのカードが並びます。
カードに出るのは次の4つだけで、細かい明細は出ません。

- 車両写真
- 仕入原価
- かかった工数（自社・外注の内訳つき）
- かかった金額（部品・外注費と人件費の内訳つき）
- 総計

カードをクリックすると、その車両の作業明細に入ります。
明細から戻るときは、左上の `← 車両一覧` かアプリ名をクリックしてください。

- `＋ 車両を追加` … 新しいアカウントを作る
- `この車両を複製` … よく使う作業構成をテンプレートとして使い回す
- 検索欄 … 車名・グレード・色・管理番号で絞り込み

### 車両写真
明細画面の「車両情報」の左に写真の枠があります。
枠をクリックしてファイルを選ぶか、写真をそのままドラッグして落としてください。

- 長辺 1280px 程度に自動で縮小して保存します（1枚 200KB 前後）
- 保存容量の都合上、写真を付けるのは 20 台前後が目安です
- 容量がいっぱいになると警告が出ます。その場合は仕上がった車両の写真を消してください

### 車両ごとの箱
左側の一覧からも車両を切り替えられます（明細画面のみ表示）。

### 作業明細
1行 = 1作業。次の項目を入力します。

| 項目 | 内容 |
| --- | --- |
| 作業日 | その作業をやった日（後述の書き方で入力） |
| 作業名 | 実施した作業 |
| 部品名 | 使った部品（品番込みで書けます） |
| 部品代 | 部品の仕入額（税込） |
| 外注費 | 外注に払った金額（税込） |
| 職人ごとの工数 | 担当した人の列に時間を入れる（0.5 刻みでOK） |
| 外注 | 外注先が使った作業時間 |

- `＋ 行を追加` / `＋ 10行` … 行を足す
- `＋ 区切り行` … 作業のまとまりを分ける見出し行（合計には入りません）
- 各行の `↑ ↓ ⧉ ✕` … 並べ替え・複製・削除
- **Enter** で真下の行の同じ欄へ移動。最終行で押すと新しい行が増えます

#### 作業日の入れ方
入力しやすい書き方をひととおり受け付けます。欄を離れると `9/3` の形に揃います。

| 入力例 | 解釈 |
| --- | --- |
| `9/3` `9-3` | 今年の9月3日 |
| `0903` | 今年の9月3日 |
| `9月3日` | 今年の9月3日 |
| `2026/9/3` `26/9/3` | 2026年9月3日 |
| `20260903` | 2026年9月3日 |

日付として読めない文字を入れた場合は、書いたままメモとして残ります。
マウスを乗せると年込みの日付が出ます。
明細の下に「作業日 9/2 〜 9/28（実働 12 日）」と期間が表示されます。

**作業者**は職人ごとの工数の列そのものが記録になります。
誰がどの作業に何時間かけたかは、その行のどの列に数字が入っているかで分かります。

### 自動集計
入力すると同時に、下記がすべて再計算されます。

```
部品代 ＋ 外注費              = 部品代＋外注費
自社作業時間合計 × 時間単価    = 人件費
自社作業時間 ＋ 外注作業時間   = 作業時間総計
仕入価格 ＋ 部品代 ＋ 外注費 ＋ 人件費 = 原価総計
```

時間単価は車両ごとに設定できます（初期値は `職人・単価` で変更）。
金額はすべて税込で扱います。

### 職人・単価
`職人・単価` ボタンから、工数を入力する人（＝表の列）を追加・並べ替え・改名できます。
名前を変えても入力済みの工数はそのまま残ります。

### 保存・書き出し
- **自動保存** … 入力するたびにブラウザ内へ保存されます（`保存済 HH:MM:SS` 表示）
- **バックアップ** … 全データを JSON ファイルに書き出し
- **復元** … バックアップした JSON を読み込んで元に戻す
- **CSV書出** … Excel でそのまま開ける CSV（この車両だけ／全車両）
- **印刷 / PDF** … A4縦で印刷。ブラウザの「PDFに保存」で PDF 化できます

### ショートカット
| キー | 動作 |
| --- | --- |
| `Enter` | 下の行の同じ欄へ |
| `Ctrl + Z` | 元に戻す |
| `Ctrl + Shift + Z` | やり直す |
| `Ctrl + S` | 即時保存 |
| `Ctrl + P` | 印刷 |

## データの保管場所についての注意

データは開いているブラウザの中（localStorage）に保存されます。そのため

- **別のPC・別のブラウザとは共有されません**
- ブラウザの「閲覧履歴データの削除」でサイトデータを消すと一緒に消えます
- 車両写真も同じ場所に入るため、容量には上限があります（おおむね5MB前後）

大事な区切り（1台仕上がったタイミングなど）では `バックアップ` を押して
JSON ファイルを保存しておいてください。

複数台のPCから同じデータを触りたい場合は、サーバーを立てて共有する形に
作り替えられます。必要になったらご相談ください。

## ファイル構成

```
index.html            画面の骨組み
assets/app.css        見た目（画面用・印刷用）
assets/js/format.js   数値の表示・入力変換
assets/js/calc.js     原価の集計ロジック
assets/js/store.js    保存・読み込み・元に戻す
assets/js/sample.js   見本データ（ユーノス 218287）
assets/js/app.js      画面の描画と操作
```

ビルド作業は不要です。ファイルを直接編集すれば、そのまま反映されます。
