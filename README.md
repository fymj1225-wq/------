# レストア原価管理

車両レストアの原価表を、車両ごとに管理するためのアプリです。
いただいた「車両管理表.xlsx」の構成をベースにしています。

## 使い方

`index.html` をブラウザで開くだけで動きます。インストールもインターネット接続も不要です。
画面は黒基調・計器盤をイメージした配色で、携帯で見ることを前提に組んであります。
金額や工数は等幅数字で表示するので、桁がまっすぐ揃います。

- PCで開く … `index.html` をダブルクリック
- 携帯で開く … このフォルダを社内サーバーや共有フォルダに置き、そのURLを開く。
  ホーム画面に追加しておくとアプリのように起動できます

そのまま開いた場合、データは**その端末のブラウザの中だけ**に保存されます。
PCと携帯で同じ内容を見たいときは、次の「共有サーバー」を使ってください。

## 携帯のアプリとして使う

**ホーム画面に追加すれば、そのままアプリになります。**
インストールもストアも要りません。手順は [DEPLOY.md](DEPLOY.md) にあります。

- iPhone … Safari で開く → 共有ボタン → 「ホーム画面に追加」
- Android … Chrome で開く → メニュー → 「アプリをインストール」

アイコンから起動すると、アドレスバーの無い全画面で立ち上がります。
見た目も動きも普通のアプリと変わりません。

### オフラインでも起動できるようにするには

アプリ本体を端末に持っておく仕組み（Service Worker）を入れてあります。
ただしブラウザの決まりで、**`https://` か `localhost` で開いたときだけ有効**です。

| 開き方 | ホーム画面に追加 | 圏外でも起動 |
| --- | --- | --- |
| `http://192.168.…`（社内LAN） | ○ | ✕（PCが必要） |
| `https://…`（ネット上に置く） | ○ | ○ |

**ネット上（HTTPS）に置けば、圏外でもアイコンから起動でき、
出先や自宅からでも同期できます。**手順は次の章にあります。

### App Store / Google Play に出す場合

技術的には、この中身をそのまま包んで本物のアプリにできます（Capacitor）。
ただし次のものが要ります。

- Apple Developer Program … 年額 99 米ドル、iOS のビルドには Mac が必要
- Google Play … 登録料 25 米ドル（初回のみ）
- 審査。社内で使うだけなら、そもそもストアに出す必要はありません

## 携帯だけで使う（いまの使い方）

サーバーも料金も要りません。**アプリのファイルを置く場所を1つ用意して、
そのURLを携帯で開き、ホーム画面に追加するだけ**です。

**入力したデータは携帯の中だけに残り、置き場所には一切送られません。**

手順は [DEPLOY.md](DEPLOY.md) にまとめてあります（Netlify にフォルダを
ドラッグするだけ。無料・カード不要）。

### バックアップだけは忘れずに

データが携帯の中だけにあるということは、**携帯を失くしたり、Safariの
「履歴とWebサイトデータを消去」を押すと一緒に消える**ということです。

- 上の `⋯` →「バックアップを保存」で共有シートが開きます。
  そのままLINEで自分宛に送るか、「ファイルに保存」でiCloud Driveに入れてください
- 1台仕上がったタイミングが目安です
- しばらく取っていないと、起動時にそっと知らせます（タップでそのまま取れます）
- 戻すときは 左上のランプ →「バックアップから戻す」

## 複数の端末で共有する（あとから必要になったら）

置き場所にサーバーを立てると、携帯を親機・PCを子機として同じデータを
共有できます。顔認証（パスキー）にも対応しています。
インターネットに置く場合の手順は、この節と次の節を見てください。

### 合言葉を用意する

長くてバラバラな文字列にしてください。作るならこれで出せます。

```
node -e "console.log(require('crypto').randomBytes(18).toString('base64url'))"
```

出てきた文字列を控えておきます。**12文字未満だとサーバーが起動しません。**

### 置き場所を作る

同梱の `Dockerfile` と `fly.toml` をそのまま使えます。Docker が動いて
消えないディスクを付けられるところなら、どこでも置けます。

```bash
fly launch --no-deploy --copy-config --name 好きな名前 --region nrt
fly volumes create restore_data --size 1 --region nrt
fly secrets set RESTORE_TOKEN='さっき作った合言葉'
fly deploy
```

> 料金は各社の設定次第で変わります。最新の金額は各社の料金ページで確認してください。

### 顔認証・指紋で開く（パスキー）

合言葉を毎回打つ必要はありません。端末ごとに一度だけ登録すれば、
あとは **Face ID / Touch ID / 指紋 / Windows Hello** で開けます。

1. 新しい端末で開くと「データを開く」と出るので、`合言葉で開く` を選んで一度だけ入力する
2. 続けて「顔認証で開けるようにする」と出るので `登録する` を押す
3. 端末の顔認証・指紋認証が出るので、いつもどおり通す
4. **登録が済むと、合言葉はその端末から消えます**

- 顔や指紋のデータが送られることはありません。照合は端末の中だけで行われ、
  やり取りされるのは「合鍵で署名した短い文字列」だけです
- 署名は毎回使い捨てです。盗み見て再送しても通りません
- `https://` かつ**ドメイン名**で開いたときだけ使えます。
  IPアドレス（`192.168.…`）では従来どおり合言葉になります

### 公開したときの守り

- 合言葉、または登録済み端末の顔認証を通らないと `/api/state` に触れません
- 合言葉を間違え続けると、そのIPからは一時的に受け付けなくなります
- 1分あたりのアクセス回数にも上限があります
- `server.js` や `README.md` など、画面に要らないファイルは配信しません
- データは `DATA_DIR` に置かれ、10分ごとに控えが残ります（最新60件）

## PCと携帯で同じデータを見る（社内LANで使う場合）

**携帯を「親機」、PCを「子機」**として使います。
この章は、ネットに置かずに工場のPCを置き場所にする場合の手順です。
（役割の考え方はネットに置いた場合も同じです）

- **親機（いつも使う携帯）** … この端末の内容が「正」。入力すると自動で共有される
- **子機（PC）** … 開くたびに親機の内容を取り込む。確認や印刷に使う

食い違ったときは**必ず親機が優先**されます。子機で加えた変更が、
知らないうちに親機の内容を書き換えることはありません。

### 置き場所について

携帯そのものはサーバーになれない（iPhone / Android では常駐プログラムが
動かせない）ので、**データの置き場所だけはPCが受け持ちます**。
「正しいのは携帯・置き場所はPC」という役割分担です。

外部のサービスもアカウントも使いません。データはそのPCの中だけに置かれます。

### 準備（最初の1回だけ）
1. 置き場所にするPCに [Node.js](https://nodejs.org/ja) の LTS 版を入れる
2. このフォルダをそのPCに置く

### 使うとき
- Windows … `start-windows.bat` をダブルクリック
- Mac … `start-mac.command` をダブルクリック

黒い画面が出て、こんな表示になれば起動しています。

```
  このPC      : http://localhost:8787/
  携帯から    : http://192.168.1.23:8787/
```

**携帯からは、下に出ている `http://192.168.…` のURLを開いてください。**
Safari の共有ボタンから「ホーム画面に追加」しておくと、アイコンから
一発で開けます。

初めて開いたときに「この端末の役割」を聞かれるので、
**携帯では「親機にする」／PCでは「子機にする」**を選んでください。
（あとから左上のランプ →「役割を変える」で変更できます）

止めるときは黒い画面で `Ctrl + C`、または画面を閉じてください。

### どう動くか

**携帯（親機）**
- 入力すると1秒ほどで自動的に送られます
- 電波が届かない間も普通に入力でき、つながった時点でまとめて送られます
- つながらない間は自動で再接続を試みます

**PC（子機）**
- **開いた瞬間に親機の内容を取りに行きます**
- 開いている間も、他の画面から戻るたび・12秒ごとに確認します
- PC側で編集した場合は自動では送りません。左上のランプが橙になり、
  「送る」か「捨てて親機に合わせる」かを選べます

**PCの電源が切れている間**は共有が止まりますが、携帯はその間も普通に
使えます。PCを立ち上げて携帯を開けば、まとめて同期されます。

### ランプの見かた
左上の丸いランプが今の状態です。押すと詳しい状態と操作が出ます。

| 色 | 意味 |
| --- | --- |
| 緑 | 共有できている |
| 橙（点滅） | 送信中 |
| 橙 | 未送信の変更がある／親機の入力待ち |
| 赤 | サーバーに繋がっていない |
| 灰 | 共有していない（この端末だけに保存） |

### 気をつけること
- **親機は1台だけ**にしてください。2台を親機にすると、後から送ったほうが残ります
- サーバーは**同じネットワークにいる人なら誰でも**開けます。
  外から見られたくない場合は、社内のWi-Fiだけで使ってください
- 合言葉を付けたい場合は `RESTORE_TOKEN=好きな文字列 node server.js` で起動すると、
  初回に合言葉を聞くようになります
- データは `data/state.json` に入り、10分ごとに `data/backups/` へ
  自動で控えが残ります（最新60件）

## 画面の構成

### トップ：車両アカウント一覧
起動するとまずこの画面です。1台＝1アカウントのカードが並びます。
カードに出るのは次の4つだけで、細かい明細は出ません。

- 車両写真（右上に状態のバッジ）
- 仕入原価
- 工数（自社・外注の内訳つき）
- 金額（部品・外注費と人件費の内訳つき）
- 総計
- 原価の内訳を1本の帯で表示（仕入＝グレー／部品・外注＝オレンジ／人件費＝グリーン）

カードをクリックすると、その車両の作業明細に入ります。
明細から戻るときは、左上の `← 車両一覧` かアプリ名をクリックしてください。

車両の呼び名は **「車名 ＋ 車台番号の下4桁」** で表示されます
（例: `ユーノス 8287`）。同じ車種が複数あっても取り違えません。
下4桁は車台番号の欄から自動で作られるので、別に入力する必要はありません。

状態は **待機・進行中・保留・完了** の4つです。色で見分けられます
（待機＝グレー／進行中＝オレンジ／保留＝赤／完了＝グリーン）。
新しく作った車両は「待機」から始まります。

- `＋ 車両を追加` … 新しいアカウントを作る（車両情報が開いた状態で出ます）
- `この車両を複製` … よく使う作業構成をテンプレートとして使い回す
- 検索欄 … 車名・グレード・色・車台番号で絞り込み（下4桁だけでも当たります）

### 車両写真
明細画面の「車両情報」の左に写真の枠があります。
枠をクリックしてファイルを選ぶか、写真をそのままドラッグして落としてください。

- 長辺 1280px 程度に自動で縮小して保存します（1枚 200KB 前後）
- 保存容量の都合上、写真を付けるのは 20 台前後が目安です
- 容量がいっぱいになると警告が出ます。その場合は仕上がった車両の写真を消してください

### 車両ごとの箱
左側の一覧からも車両を切り替えられます（明細画面のみ表示）。

### 作業明細
1行 = 1作業。次の項目を入力します。

| 項目 | 内容 |
| --- | --- |
| 作業日 | その作業をやった日（後述の書き方で入力） |
| 作業名 | 実施した作業 |
| 部品名 | 使った部品（品番込みで書けます） |
| 部品代 | 部品の仕入額（税込） |
| 外注費 | 外注に払った金額（税込） |
| 職人ごとの工数 | 担当した人の列に時間を入れる（0.5 刻みでOK） |
| 外注 | 外注先が使った作業時間 |

- `＋ 行を追加` / `＋ 10行` … 行を足す
- `＋ 区切り行` … 作業のまとまりを分ける見出し行（合計には入りません）
- 各行の `↑ ↓ ⧉ ✕`（携帯は `⋮`）… 並べ替え・複製・削除
- **Enter** で真下の行の同じ欄へ移動。最終行で押すと新しい行が増えます

#### 作業日の入れ方
入力しやすい書き方をひととおり受け付けます。欄を離れると `9/3` の形に揃います。

| 入力例 | 解釈 |
| --- | --- |
| `9/3` `9-3` | 今年の9月3日 |
| `0903` | 今年の9月3日 |
| `9月3日` | 今年の9月3日 |
| `2026/9/3` `26/9/3` | 2026年9月3日 |
| `20260903` | 2026年9月3日 |

日付として読めない文字を入れた場合は、書いたままメモとして残ります。
マウスを乗せると年込みの日付が出ます。
明細の下に「作業日 9/2 〜 9/28（実働 12 日）」と期間が表示されます。

**作業者**は職人ごとの工数の列そのものが記録になります。
誰がどの作業に何時間かけたかは、その行のどの列に数字が入っているかで分かります。

### 自動集計
入力すると同時に、下記がすべて再計算されます。

```
部品代 ＋ 外注費              = 部品代＋外注費
自社作業時間合計 × 時間単価    = 人件費
自社作業時間 ＋ 外注作業時間   = 作業時間総計
仕入価格 ＋ 部品代 ＋ 外注費 ＋ 人件費 = 原価総計
```

時間単価は車両ごとに設定できます（初期値は `職人・単価` で変更）。
金額はすべて税込で扱います。

### 職人・単価
`職人・単価` ボタンから、工数を入力する人（＝表の列）を追加・並べ替え・改名できます。
名前を変えても入力済みの工数はそのまま残ります。

### 保存・書き出し
- **自動保存** … 入力するたびにブラウザ内へ保存されます（`保存済 HH:MM:SS` 表示）
- **バックアップ** … 全データを JSON ファイルに書き出し
- **復元** … バックアップした JSON を読み込んで元に戻す
- **CSV書出** … Excel でそのまま開ける CSV（この車両だけ／全車両）
- **印刷 / PDF** … A4縦で印刷。ブラウザの「PDFに保存」で PDF 化できます。
  紙の体裁は元の車両管理表に合わせてあります。原価サマリーは1枚目の上、
  明細の合計は最後のページに1回だけ出ます

### ショートカット
| キー | 動作 |
| --- | --- |
| `Enter` | 下の行の同じ欄へ |
| `Ctrl + Z` | 元に戻す |
| `Ctrl + Shift + Z` | やり直す |
| `Ctrl + S` | 即時保存 |
| `Ctrl + P` | 印刷 |

## データの保管場所についての注意

データは開いているブラウザの中（localStorage）に保存されます。そのため

- **別のPC・別のブラウザとは共有されません**
- **同じ端末の同じブラウザでのみ引き継がれます**（PCと携帯は別々）
  ※ 親機・子機として共有している場合は、すべての端末で同じ内容になります
- ブラウザの「閲覧履歴データの削除」でサイトデータを消すと一緒に消えます
- 車両写真も同じ場所に入るため、容量には上限があります（おおむね5MB前後）

大事な区切り（1台仕上がったタイミングなど）では `バックアップ` を押して
JSON ファイルを保存しておいてください。

複数台のPCから同じデータを触りたい場合は、サーバーを立てて共有する形に
作り替えられます。必要になったらご相談ください。

## ファイル構成

```
index.html               画面の骨組み
manifest.webmanifest     ホーム画面に追加したときの設定
DEPLOY.md                携帯で使えるようにする手順書
robots.txt               検索結果に出さないための指定
sw.js                    オフライン起動の仕掛け（Service Worker）
server.js                共有サーバー（Node.js だけで動く／外部ライブラリなし）
webauthn.js              顔認証（パスキー）とログイン状態の検証
package.json             起動用の設定
Dockerfile               ネット上に置くときのイメージ定義
fly.toml                 Fly.io に置くときの設定例
start-windows.bat        Windows でサーバーを起動する
start-mac.command        Mac でサーバーを起動する
assets/app.css           見た目（黒基調の画面用・携帯用・印刷用）
assets/icon-180.png      アイコン
assets/icon-512.png
assets/js/format.js      数値・日付の表示と入力変換
assets/js/calc.js        原価の集計ロジック
assets/js/store.js       保存・読み込み・元に戻す
assets/js/passkey.js     顔認証・指紋認証
assets/js/sync.js        親機・子機の同期
assets/js/sample.js      見本データ（ユーノス 218287）
assets/js/app.js         画面の描画と操作
data/state.json          共有サーバーを使うときのデータ（自動で作られる）
```

ビルド作業は不要です。ファイルを直接編集すれば、そのまま反映されます。
